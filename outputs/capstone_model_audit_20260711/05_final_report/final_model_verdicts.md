# Final Model Verdicts

## Evidence language

- **Directly proven** means reproduced from source, bytes, model execution, or raw rows in this audit.
- **Strong but incomplete** means multiple repository artifacts agree, but an original invocation, full protocol, or external runtime is absent.
- **Interpretation** is an audit judgment derived from the proven facts.
- **Unsupported or unknown** is not usable as a fact without new evidence.

The classifications and confidence levels below are the final adjudications in `final_scorecard.md`.

## Final disposition

- **Keep as repository baseline with explicit caveats:** KonIQ/FLIVE image technical policy and the default Stage5 server policy, while correcting their contracts before using them as evidence of model quality.
- **Best candidates for a controlled deployment-validation phase:** fixed NIMA, RGNet PIL-resize, and Mobile A-LAMP v2.
- **Research/reference only:** MDIQA teacher, paper-v1 RGNet, TOPIQ branches, all guards/students, practical MUSIQ probes, and A-LAMP teachers.
- **Do not ship under the present contract:** FLIVE patch as a mobile model, legacy NIMA, practical RGNet/A-LAMP without corrected preprocessing, and ICAA FP16 with the current lab settings or size.
- **Unverified:** external Kaggle MUSIQ identity and the aggregate VILA/Gemma line.
