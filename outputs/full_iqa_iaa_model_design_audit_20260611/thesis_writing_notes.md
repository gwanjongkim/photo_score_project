# 논문 / 캡스톤 작성 노트 (A-CUT IQA/IAA 모델 설계)

## 1. 왜 모델 앙상블을 사용했는가
- 단일 경량 모바일 모델로는 정확도·속도·안정성·교정을 이질적 데이터셋 전반에서
  동시에 만족시킬 수 없다. 기술 품질은 KonIQ-10k / SPAQ / FLIVE, 미학 품질은
  AVA / AADB / ICAA17K로 정의되며, 각 데이터셋의 라벨 스케일과 "품질"의 정의가 다르다.
- 모델 간 상호 보완성이 핵심이다. 교차 데이터셋 기준선에서 RGNet은 AADB(0.668)에서
  강하지만 AVA(0.196)에서는 약하고, NIMA는 AVA(0.623)에서 강하다. 기술 측에서는
  KonIQ가 FLIVE의 과대평가(심각 오탐 189건)를 교정한다. 즉 앙상블의 다양성은 중복이
  아니라 서로의 사각지대를 메우는 실질적 역할을 한다.

## 2. 왜 모바일 제약이 중요한가
- 제품 목표는 학술 벤치마크 재현이 아니라 "온디바이스에서 사용자의 사진을 신뢰성
  있게 랭킹"하는 것이다. 한 장당 (모델 수 × 지연시간)이 앨범 단위 비용을 결정하므로,
  벤치마크 점수보다 지연시간·안정성·심각 오탐 억제·설명 가능성이 배포 가능성을
  좌우한다.
- 대표 지연시간(프로젝트 컨텍스트 Android 로그 기준): NIMA ~177 ms, RGNet ~302 ms,
  A-LAMP ~49 ms, ICAA ~1.1 s, KonIQ/FLIVE 각 ~25 ms. ICAA 하나가 나머지 미학
  앙상블 전체(~528 ms)의 약 2배 비용이다.

## 3. 왜 강력한 연구 모델을 배포하지 않았는가
- MDIQA Teacher(SRCC 0.8227, 심각 오탐 0)와 TOPIQ+FLIVE(SRCC 0.8069)는 프로덕션
  KonIQ+FLIVE(0.7168)보다 벤치마크가 높다. 그러나 MDIQA는 PyTorch 트랜스포머로
  실시간 모바일 실행이 불가능하고, TOPIQ+FLIVE는 심각 오탐 3건을 유발한다.
- 베스트샷 선택에서 가장 치명적인 실패는 "기술적으로 망가진 사진을 최고로 선택"하는
  것이므로, "가장 높은 점수"가 아니라 "가장 안전한 모델"(심각 오탐 0)을 프로덕션으로
  선택한 것이 제품 관점에서 옳다. 이 절충은 논문에 명시적으로 기술해야 한다.

## 4. 왜 부정적 결과(Negative Result)가 중요한가
- MDIQA 학생 No-Go: 강력한 교사가 우수한 학생을 보장하지 않는다. 50k B0 학생은
  0.7033에 그쳤고 가중치·랭킹 손실·라벨 스케일링 등 모든 교정 시도가 0.48~0.54로
  오히려 퇴보했다. 파이프라인·데이터·구조 오딧은 모두 통과했으므로 이는 버그가 아니라
  증류의 근본 한계(용량, 교차 데이터셋 라벨 압착, FLIVE 정렬 약화)이다.
- TechIQA-Guard v1 No-Go: 단일 헤드로 품질과 기술 결함을 동시에 학습시키자 "예쁘지만
  기술적으로 나쁜" 이미지에서 점수가 누출되어(하드 오탐 평균 68.07 vs 프로덕션 61.02)
  안전 가드가 약화되었다. → 기술/미학 분리와 후기 융합의 정당성을 역으로 입증한다.
- 부정적 결과는 기존 검증된 스택의 견고함을 데이터로 입증하고, 검증되지 않은 교체로
  인한 위험과 자원 낭비를 막은 의사결정 근거가 된다.

## 5. 최종적으로 방어 가능한 아키텍처
- **기술 IQA:** KonIQ + FLIVE 앙상블(심각 오탐 0, ~50 ms).
- **미학 IAA:** NIMA + RGNet + Mobile A-LAMP v2, 교정 후 가중 후기 융합
  (제출 앱 기본값: NIMA 0.40 / RGNet 0.45 / A-LAMP 0.15; 오프라인 추천값: 0.37 / 0.41 / 0.22).
- **결합:** 기술과 미학을 분리 산출 후 late fusion. 디버그 UI에서 모델별 서브
  스코어 노출로 설명 가능성과 디버깅 확보.
- **연구·참조용:** MDIQA Teacher/학생, ICAA(색채 서브 스코어), TOPIQ+FLIVE(로그 전용).

## 6. 한계 및 향후 연구(현재 즉시 실행 항목 아님)
- 현재 미학 결합 SRCC(~0.66)는 벤치마크 내 프록시이며 실제 Pozy 사용자 사진에서
  검증된 값이 아니다 → 사용자 사진 기반 랭킹 검증이 향후 과제.
- 향후 연구 후보(연구 전용 표기): 도메인 인식/멀티 헤드 기술 학생, 심각 오탐
  안전 게이트가 포함된 교정 TOPIQ+FLIVE, 지연시간 개선용 ICAA 풀 정수 PTQ.
