# A-cut 캡스톤 주차별 연구일지 v2 (Strict Evidence)

본 문서는 A-cut 캡스톤 프로젝트의 연구 과정을 주차별로 기록한 엄격한 근거 기반 보고서입니다.

## 생성 내역
- **주차별 상세 파일**: `weeks/` 디렉토리에 각 주차별 활동, 결과, 산출물을 상세히 기록하였습니다.
- **주제별 요약**: `topics/` 디렉토리에 주요 연구 주제(미적/기술적 품질, VLM, Gemma, Firebase 등)별 누적 성과를 정리하였습니다.
- **근거 인덱스**: `evidence_index.csv`를 통해 모든 기록의 원본 파일과 신뢰도를 추적할 수 있습니다.

## 수집 방법
1.  **전수 조사**: 리포지토리 전체를 대상으로 주요 키워드(Gemma, VILA, Firebase, NIMA 등) 검색을 수행하였습니다.
2.  **날짜 추출**: 파일명에 포함된 날짜를 최우선으로 하였으며, 부재 시 파일 내용의 타임스탬프와 수정 시간을 활용하였습니다.
3.  **근거 기반 작성**: 모든 수치는 원본 보고서와 로그 파일에서 직접 추출하였으며, 근거가 불확실한 경우 명시적으로 표기하였습니다.

## 확인된 주요 사항
- **Gemma/LiteRT**: Gemma 어댑터 학습 기록(282개 샘플)을 확인하였으나, 시각적 환각 문제로 배포가 보류된 사실을 확인했습니다.
- **Firebase**: Firestore와 Storage를 활용한 비동기 작업 큐 아키텍처와 로컬 워커 스모크 테스트 기록을 확인했습니다.
- **VLM/Reasoning**: NVILA-8B 및 VILA-lite를 활용한 시각적 이유 생성 파이프라인과 Selector 통합 기록을 확인했습니다.
- **NIMA 버그 수정**: 전처리 중복 스케일링 버그 수정 전후의 성능 차이(SRCC 0.34 -> 0.59)를 확인했습니다.

## 미완료 및 보류 사항
- **A-LAMP 그래프 퓨전**: 소규모 데이터셋에서의 과적합 문제로 연구가 보류되었습니다.
- **RGNet DenseASPP**: 최신 실험 결과가 베이스라인 성능을 넘어서지 못했음을 확인했습니다.
