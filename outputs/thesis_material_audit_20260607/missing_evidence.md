# 논문 작성을 위해 추가 확인이 필요한 자료 (Missing Evidence)

현재 레포지토리 내의 실험 및 메트릭 기록은 훌륭하게 보존되어 있으나, 실제 논문(Paper/Thesis)으로 완성하기 위해 다음 항목들이 추가로 필요하거나 확인되어야 합니다.

## 1. 누락된 시스템 시각화 자료 (Missing Figures)
*   **A-cut 전체 시스템 아키텍처 다이어그램:** 모바일(Android/Flutter)과 모델(TFLite)이 상호작용하는 아키텍처 다이어그램이 문서화되어 있지 않습니다.
*   **지식 증류 파이프라인 개념도:** 다수의 Teacher 모델(A-LAMP, RGNet)에서 단일 Student 모델(Stage 5)로 지식이 전달되는 구조를 보여주는 시각 자료가 필요합니다.
*   **스마트폰 구동 스크린샷 (App Screenshots):** "모바일 온디바이스 시스템"을 주장하기 위해, 실제 앱 구동 화면이나 데모 결과 캡처가 필요합니다.

## 2. 모바일 추론 속도 (Latency) 상세 데이터
*   모바일 배포(Mobile Deployment)를 결정한 주요 요인이 모델의 크기와 입력 형태(다중 패치 불가)임은 명시되어 있으나, **실제 안드로이드 기기에서의 추론 소요 시간(ms)** 데이터가 명확하게 요약된 표가 부족합니다.
*   `android_gemma_latency_harness` 디렉토리가 존재하나, IQA/IAA(TFLite) 모델들의 기기별(ex. Pixel, Galaxy) 프레임 처리 속도 데이터가 집계되어야 합니다.

## 3. 정성적 평가 결과 (Qualitative Results)
*   모든 결과가 정량적 메트릭(SRCC, Accuracy, MAE)으로만 제공되고 있습니다.
*   앙상블 모델과 단일 모델이 점수를 다르게 매긴 **실제 사진 예시(성공 및 실패 케이스)** 그림이 추가되어야 독자들의 이해도를 높일 수 있습니다.

## 4. 사용자 확인 필요 사항 (Needs User Confirmation)
*   Stage 5 Student 모델이 최종 모바일 배포용으로 확정된 것이 맞는지, 혹은 더 이상의 튜닝이 진행되었는지 최신 스테이터스 확인.
*   MDIQA 모델이 최종적으로 베이스라인으로만 쓰이고 기각된 것인지 확인 필요.
