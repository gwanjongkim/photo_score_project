# 학습 계보 누락 항목 (Missing Training Provenance)

## 1. KonIQ / FLIVE 상세 파라미터
- **누락 사항**: `train_regression.py`를 사용하여 학습된 것은 확실하나, 학습 당시의 구체적인 하이퍼파라미터(Epochs, Learning Rate, Batch Size)가 기록된 개별 `.json` 또는 `.log` 파일이 유실되었거나 `outputs/`의 다른 이름으로 저장되어 있음.
- **영향**: 모델 재현 시 동일한 가중치 수렴을 보장하기 어려울 수 있으나, 코드와 체크포인트가 존재하므로 위험도는 낮음.

## 2. ICAA 파인튜닝 데이터셋
- **누락 사항**: ICAA가 TF-native로 재구축된 이후, 별도의 내부 데이터셋(AADB 등)으로 파인튜닝되었는지에 대한 명시적인 기록이 없음.
- **영향**: 현재는 공식 가중치 기반 성능만 확인된 상태임.

## 3. RGNet/A-LAMP의 훈련 로그 파일
- **누락 사항**: `outputs/` 폴더 내에 `summary.json`은 존재하지만, 학습 과정 중의 Stdout/Stderr 전체 로그 파일이 일부 유실됨.
- **영향**: 학습 도중 발생한 경고나 세부 수렴 추이를 정밀 분석하는 데 한계가 있음.
