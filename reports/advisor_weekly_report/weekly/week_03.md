# 3주차 보고서: VLM 기반 시각적 설명(Reasoning) 생성 탐색

## 1. 이번 주 목표
선별된 사진에 대해 사용자가 납득할 수 있는 추천 이유 텍스트 생성 테스트

## 2. 수행한 작업
- NVILA-8B 모델 로컬 평가 (Probe v1 ~ v10)\n- VILA-lite 모바일 핸드오프 검토

## 3. 실험 및 구현 내용
로컬 GPU 환경에서 거대 언어 모델인 NVILA-8B를 띄워 이미지에 대한 미적 점수 추론 및 텍스트 설명 생성을 반복 실험.

## 4. 결과
**설명 텍스트 생성에는 성공했으나, VRAM 메모리 사용량이 극도로 높아 모바일 또는 실시간 백엔드 적용에 제약 발견.**

## 5. 성공 / 실패 / 보류 판단
- **판단 결과**: 실패/보류 (온디바이스 실행 불가, 클라우드 실행 시에도 비용 및 인프라 과부하 예상. 따라서 추후 Gemini API로 선회함)

## 6. 근거자료 설명
- 근거 파일: `outputs/acut_product_nvila8b_probe_v10_gpu/top_k_summary.json`\n- 의미: NVILA-8B 모델의 텍스트 생성 결과 요약.\n- 핵심 내용: 생성은 되나 시스템 리소스 한계 이슈 내포.\n- 보고서 주장: 거대 VLM 모델을 직접 구동하려 했으나 리소스 제약으로 보류함.

## 7. 시각자료
*관련 타임라인 및 전체 모델 상태는 통합 보고서(`final_professor_report.md`)와 `figures/` 디렉토리의 전체 차트를 참조해 주십시오.*
