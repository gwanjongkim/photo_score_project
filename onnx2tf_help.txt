  -coion, --copy_onnx_input_output_names_to_tflite
                        Copy the input/output OP name of ONNX to the
                        input/output OP name of tflite. Due to Tensorflow
                        internal operating specifications, the input/output
                        order of ONNX does not necessarily match the
                        input/output order of tflite. Be sure to check that
                        the input/output OP names in the generated tflite file
                        have been converted as expected. Also, this option
                        generates a huge JSON file as a temporary file for
                        processing. Therefore, it is strongly discouraged to
                        use it on large models of hundreds of megabytes or
                        more.

                        "tf_converter": Use TensorFlow Lite Converter as an
